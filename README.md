# Mango E-Commerce Store

A modern e-commerce platform for selling mangoes online, featuring a customer storefront and a comprehensive admin panel.

## Features

### Customer Store

* Product browsing and categories
* Product details
* Shopping cart
* Checkout
* Order management
* Responsive design
* Search and filtering

### Admin Panel

* Product management
* Add, edit, and delete products
* Inventory management
* Order management
* Customer management
* Dashboard and sales overview
* Product pricing management

## Technologies

* TypeScript
* React
* Next.js
* Tailwind CSS
* PostgreSQL


## Project Highlights

* Responsive and modern e-commerce UI
* Admin dashboard for managing store operations
* REST API integration
* Database-driven product and order management
* Structured frontend and backend architecture
